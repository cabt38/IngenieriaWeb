Propósito del proyecto

Este sitio fue desarrollado como práctica evaluativa de la asignatura Ingeniería Web (Universidad Cooperativa de Colombia). Su objetivo es integrar HTML semántico, CSS, arquitectura cliente-servidor, formularios, procesamiento de peticiones POST, validación en el servidor y persistencia de datos con SQLite.

Contexto

La temática asignada es un restaurante. La aplicación simula el proceso de un cliente que se registra en el sistema y, posteriormente, utiliza su identificador para reservar una mesa a través del formulario de servicios.
